⌚ Garmin Forerunner 기록 가져오기 · 거리 수정판

Garmin Connect 웹사이트에서 개별 활동을 TCX 또는 GPX로 내보내고 여기에서 선택하세요.

TCX 권장: 운동 날짜, 거리, 시간과 제공되는 경우 심박수·누적 오르막을 읽습니다. GPX는 GPS 경로와 시간 정보가 충분히 있을 때 사용합니다. FIT 원본, ZIP, CSV는 이 버전에서 지원하지 않습니다. 파일은 서버에 전송되지 않고 이 브라우저 안에서 처리됩니다.

파일을 선택하면 가져오기 결과가 표시됩니다.

갤럭시에서 내보내는 방법

① Chrome에서 Garmin Connect 웹 로그인 → ② 활동 목록에서 러닝 선택 → ③ 화면 우측 상단 설정(톱니바퀴) → ④ TCX로 내보내기 → ⑤ 다운로드한 .tcx 파일을 위에서 선택

휴대폰에서 메뉴가 안 보인다면 Chrome의 '데스크톱 사이트'를 켜거나 PC에서 내보내세요. 가져온 기록은 기존 RUN 21.1 기록과 함께 표시되며, 동일 파일을 다시 가져오면 중복 감지합니다. 파일의 시간은 가능한 경우 움직인 시간이 아닌 기록 전체 경과 시간일 수 있습니다.
